# Mid-term (Milestone 2) material — kept for reference

This folder holds everything we submitted at the mid-term review, unchanged.

**Important:** the mid-term dataset (`dataset/curriculum_reading_dataset.csv`) is synthetic.
Its 160 rows reuse only 15 template passages, so it is not suitable for training models.
For the final milestone we replaced it with the real CLEAR corpus (see the main README).

To regenerate the mid-term files, run the scripts from inside this folder, e.g.
`cd midterm && python scripts/generate_midterm_report.py`.
